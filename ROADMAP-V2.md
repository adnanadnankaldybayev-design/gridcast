# GridCast — ROADMAP V2 (мега-план «как у организации»)

Решение владельца 2026-09-26: GridCast — единственный проект, делаем его
максимально глубоко и масштабно, дни/недели работы. Остальные 8 проектов
портфолио — заморожены до его завершения.

Северо-звезда: **самый открытый и честный публичный бенчмарк прогноза спроса на
электроэнергию, который обновляется сам каждый день** — данные, код, модели,
метрики, ошибки — всё публично и воспроизводимо.

## Фазы (каждая неделя = ≥1 shipped-инкремент, каждый инкремент: build → G3-ревью → push)

### Фаза B «Наука» (E3–E6) — модели и методология
- E3 Фичи+LightGBM (в работе): календарь, погода (Open-Meteo), лаги; ablation без
  погоды; срезы по типам дней; H1-вердикт по рынкам.
- E4 Зоопарк моделей: сезонно-наивная, линейная (ridge), GBM, zero-shot Chronos.
  Единый интерфейс, единый протокол.
- E5 Ансамбль + вероятностный прогноз: конформные интервалы (PICP/ширина),
  калибровка по рынкам и типам дней.
- E6 Статистика: тесты Диболда–Мариано на значимость различий моделей; статья
  «model card / benchmark card» с честным анализом ошибок.

### Фаза C «Охват» (E7–E8) — мульти-региональное расширение
- E7 Новые рынки по результатам research (кандидаты: Франция RTE éCO2mix,
  Германия SMARD, Финляндия Fingrid, Дания Energinet, Бельгия Elia, Канада AESO,
  США EIA (ключ), ENTSO-E (токен), Япония OCCTO): per-source адаптеры в том же
  контракте → цель 8–12 рынков без ключей.
- E8 Единый публичный датасет: нормализованный мировой ряд, версиирование,
  релиз на HuggingFace Datasets (+ Zenodo DOI при стабилизации).

### Фаза D «Платформа» (E9–E11) — продукт
- E9 Дашборд v2: мультирынки на одном сайте, карта, доверительные ленты,
  переключатели моделей, «вчера: прогноз vs факт», страница методологии,
  страница ошибок по типам дней. Dark, мобильный, a11y.
- E10 Публичный read-only API (статический JSON на Pages + документация
  OpenAPI-стилем) + embeddable-виджет.
- E11 Автоматические еженедельные отчёты (markdown на сайте): недельные метрики,
  аномалии недели, штрафные дни моделей — «организация отчитывается сама».

### Фаза E «Репутация» (E12–E13)
- E12 Бенчмарк против операторских прогнозов (GB day-ahead и др. по доступности)
  + накопление винтажей прогнозов (forecast snapshots) для честного H3.
- E13 Open-source гигиена: CONTRIBUTING, issue-шаблоны, discussions, релизы с
  тегами и changelog, DOI, badges; приглашение внешних пользователей.

### Фаза F «Надёжность» (постоянно, вплетено)
- Healthcheck-механика (fail на пропущенной дате), retention raw-файлов,
  pre-commit, покрытие кода отчётом, зависимости пинятся, security-прочёски
  перед каждым пушем.

## Журнал статуса

- 2026-09-26: E0+E1 shipped (3 рынка, 331k строк); E2 shipped (backtest, naive
  baseline: IE MAPE 4.2%, GB 11.1% из-за 21д лага, NEM sMAPE 5.2%); E3 в работе;
  research-заход по новым рынкам в работе.
